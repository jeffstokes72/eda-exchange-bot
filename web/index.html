Buyback Sweep Log

Every manual or auto buyback attempt (and dry-run refresh) classifies each player sell listing on the selected exchange. There is no live market average — caps are threshold % of the seeded NPC price at that grade. If the per-unit ask qualifies, the whole listed stack is bought in one pass; multiple stacks are separate orders.

Codes: 0x0 success, 0x1 price too high, 0x2 no reference price, 0x3 invalid price, 0x4 invalid stack, 0x5 max buys limit, 0x6 skipped locked.

Each batch is labeled with the exchange it ran against, and a running sweep keeps that exchange even if you change the selector. Batches stored before 0.13.4 show Legacy exchange unknown.

Server-Side Buyback Schedule

The console runs the buyback sweep unattended, so this page does not need to stay open. Scheduled and manual server-side runs use the saved values below with the exchange selected in Exchange Controls at save time; save the schedule before using Run Sweep Now. Every run probes eligibility with a read-only query first and takes a backup only when there is something to buy. All SQL is built by the console from the bundled seed plan.

Console version note: scheduled buyback SQL lives in the console (addonJobs.js), not in this page. Current RedBlink builds (aligned 2026-07-29) match per-grade caps, whole-stack quantity (GREATEST(item, initial)), and nearest-grade fallback. Older consoles may still use grade-0 base caps / single-unit stacks — upgrade the console if unattended buys look wrong. The Buyback Sweep Log above only records in-page / auto sweeps from this page, not console-scheduled runs.

Enabling requires the scheduler:server permission to be approved in the console's Addons panel. The first run fires one full interval after enabling; the schedule survives console restarts. While the server-side schedule is enabled, the in-page auto buyback checkbox is turned off: concurrent sweeps are safe at the database level but redundant, and each takes its own backup.

Server-Side Market Reseed Schedule

The console runs the NPC market reseed unattended (same RedBlink scheduler service as buyback), so this page does not need to stay open. Saved values below use the exchange selected in Exchange Controls at save time. Every run takes a database backup, clears the bot's own listings on that exchange, then seeds fresh from the bundled plan — player listings are never touched. All SQL is built by the console; this page only sends typed parameters.

Default interval is 15 minutes. Each cycle creates a full database backup, so raise the interval (30–60+) if backups pile up. Requires a console build that exposes scheduler.seed.* (see console-patches/ until RedBlink merges it). Older consoles keep this section hidden and use the in-page auto reseed checkbox above.

Enabling requires the scheduler:server permission. The first run fires one full interval after enabling. While this schedule is enabled, the in-page auto reseed checkbox is turned off to avoid redundant backups.
